# Phase 6 — Header, BottomNav and Internal Pages

تم تطبيق نظام القياسات الموحد على التنقل والصفحات الداخلية دون تغيير المسارات أو البيانات أو صلاحيات الوصول.

## Header وBottomNav

- قياسات Fluid للحاوية والفواصل والأزرار.
- حد أدنى مناسب للمسّ على أزرار اللغة والثيم والدخول والخروج.
- BottomNav ثابت للهاتف مع safe-area وbackdrop blur.
- توزيع متساوٍ لعناصر BottomNav مع قص النص الطويل بأمان.
- حجز مساحة أسفل المحتوى حتى لا يغطي BottomNav البطاقات.
- إزالة CSS المضمن من BottomNav ونقله إلى النظام العام.
- التنقل الحالي والـ active state محفوظان.

## Dashboard وHistory وStatistics

- شبكة بطاقات وإحصاءات باستخدام `minmax` و`auto-fit`.
- Hero وtabs وquick actions قابلة للانكماش والالتفاف.
- إبقاء وقت الفحص ظاهراً على الهاتف بدلاً من فقده.
- جعل صفوف الفحوصات والأنشطة والنصوص الطويلة آمنة من التمدد الأفقي.
- قياسات بطاقات Fluid مع نقاط انتقال واضحة للشاشات الصغيرة.

## الصفحات الداخلية المشتركة

تم تحسين `advanced-pages.css` للصفحات التي تعتمد عليه، ومنها تفاصيل الفحص والمقارنة والتقارير والإشعارات وإعدادات التنبيهات:

- حاوية موحدة.
- بطاقات وشبكات Fluid.
- تفاصيل metadata متجاوبة.
- جداول المقارنة قابلة للتمرير الأفقي داخل الحاوية فقط.
- دعم آمن للشاشات الصغيرة جداً.
