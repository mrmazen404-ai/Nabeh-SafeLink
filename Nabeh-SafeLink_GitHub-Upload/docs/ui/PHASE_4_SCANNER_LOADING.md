# Phase 4 — Scanner and Loading Screen Responsive Layer

تم تطبيق نظام القياسات الموحد على Scanner وLoading Screen دون حذف أو تغيير وظائف الفحص.

## Scanner

تم الحفاظ على وضعَي `URL` و`TEXT`، وحقل الإدخال، واللصق والمسح، ورسائل الخطأ، وزر الفحص، وإشعار الضيف، وسجل الفحوصات للحساب المسجل.

طبقة العرض الجديدة تجعل شبكة Scanner والحاويات والـ trust badges والأزرار والـ recent scans قابلة للانكماش. على الهاتف تتحول الشبكة إلى عمود واحد، وتصبح البطاقات ذات padding fluid، وتلتف الرسائل الطويلة بدلاً من الخروج من الشاشة. كما أزيل تنسيق React المكرر الذي كان يفرض شبكة `65% / 35%` ويتعارض مع CSS الموحد؛ لم يتغير أي سلوك أو مسار.

## Loading Screen

تم الحفاظ على spinner، الرسائل المتبدلة، progress، URL أو نص الرسالة، timeout notice، زر الإلغاء، والنصيحة السفلية. تم جعل البطاقة والـ spinner والعناوين وشريط التقدم وصندوق الرابط والأزرار Fluid، مع حالة خاصة للشاشات شديدة الصغر.
