## نطاق التجميد

هذه المرحلة تجمّد السلوك الحالي قبل إعادة ترتيب الواجهة. لا يجوز أثناء مراحل التصميم التالية تغيير:

- API أو أسماء endpoints أو payloads.
- منطق المصادقة وOTP واستعادة كلمة المرور.
- منطق الفحص ونتائجه أو نماذج ML/Gemini/VirusTotal.
- مسارات React أو صلاحيات الوصول.
- مفاتيح التخزين الحالية في `sessionStorage`.
- النصوص والترجمات والصفحات أو الأزرار الموجودة.
- وظائف Light/Dark وRTL/LTR.

التعديلات المسموحة في المرحلة البصرية هي ترتيب العناصر، العرض، الارتفاع، الـ spacing، الـ responsive breakpoints، وأسلوب العرض فقط، مع بقاء الوظيفة والبيانات كما هي.

## ملاحظات لا تُعد تغييرات في هذه المرحلة

1. يوجد فرق سابق معروف بين بعض ملفات `frontend/dist` و`public` في أسماء assets؛ تم توثيقه في نتيجة الفحص، ولم يُعالج هنا حتى لا تختلط مشكلة النشر مع إعادة التصميم.
2. يوجد احتمال معالجة غير آمنة لقيمة OTP التالفة في `sessionStorage`؛ سيتم إصلاحه في مرحلة تنفيذ منفصلة مع اختبار، وليس ضمن الجرد.
3. جميع الادعاءات النصية والأرقام المعروضة للمستخدم محفوظة كما هي الآن؛ لن تُعدّل ضمن إعادة التصميم إلا بقرار مستقل.
