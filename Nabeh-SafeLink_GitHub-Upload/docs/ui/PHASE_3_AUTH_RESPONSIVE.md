# Phase 3 — Welcome and Auth Responsive Layer

تم تطبيق طبقة العرض الجديدة على `WelcomePage` وصفحات المصادقة دون تغيير JSX أو API أو مسارات التنقل.

## ما تم الحفاظ عليه

- كل أزرار Welcome.
- تسجيل الدخول والتسجيل ونسيان كلمة المرور.
- إدخال OTP المكون من 6 خانات واللصق وإعادة الإرسال.
- Reset Password.
- Auth controls للغة والثيم والعودة إلى Welcome.
- RTL/LTR وLight/Dark.

## المقاسات المستهدفة

تستخدم الصفحة قياسات Fluid من `theme.css`، مع حالات خاصة للشاشات الصغيرة حتى 340px و380px و480px و640px. الهدف هو منع القص والـ overflow وليس تقليل المحتوى أو إخفاء الوظائف.

## قواعد التخطيط

- Welcome يبدأ من مرجع الهوية الحالي مع gutters وارتفاعات fluid.
- أزرار Welcome تصبح بعرض كامل على الهاتف كما في التصميم الحالي، مع الحفاظ على عددها وترتيبها.
- Auth shell يستخدم `min(100%, 460px)` وpadding متدرج.
- الحقول والأزرار تستخدم `--control-height` وهدف لمس لا يقل عن 44px.
- OTP يستخدم ست خانات متساوية `minmax(0, 1fr)` مع حجم مربع fluid.
- شريط Auth لا يتداخل مع عناصر التحكم العلوية على الهاتف.
