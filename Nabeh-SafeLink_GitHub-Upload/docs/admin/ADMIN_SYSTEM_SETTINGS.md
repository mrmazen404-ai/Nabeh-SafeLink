# إعدادات النظام المركزية

تضيف هذه المرحلة تحكمًا مركزيًا من لوحة Admin في إعدادات Nabeh SafeLink. لا تتصل واجهة المستخدم بقاعدة البيانات مباشرة؛ تمر كل القراءة والكتابة عبر FastAPI.

## النشر

1. تأكد من تطبيق `backend/sql/nabeh_complete_database_study_schema.sql` و`backend/sql/admin_schema.sql` في Supabase.
2. طبّق `backend/sql/admin_system_settings.sql` مرة واحدة قبل نشر نسخة Backend/واجهات جديدة. ينشئ الملف القيم الافتراضية وRPC آمنًا لتحديث الإعدادات وتسجيل `SYSTEM_SETTINGS_UPDATED` داخل معاملة قاعدة بيانات واحدة.
3. انشر Backend والواجهتين بعد نجاح migration. الاختبارات المحلية لا تتصل بقاعدة الإنتاج ولا تنفذ migration تلقائيًا.

## الواجهات

- `GET /api/v1/public/runtime-config`: يعرض قائمة حقول عامة محددة فقط؛ لا يعرض صفوف الإعدادات الخاصة أو مفاتيح الخدمات.
- `GET /api/v1/admin/settings`: يحتاج `settings.read`.
- `PATCH /api/v1/admin/settings`: يحتاج `settings.manage`، ويقبل فقط مفاتيح قائمة السماح وأنواعها المحددة.

المسؤول `SUPER_ADMIN` وحده يملك `settings.read` و`settings.manage` وفق RBAC الحالي. التحديثات تحفظ قيم `before_data` و`after_data` المقنّعة مع معرّف الطلب وبصمتي عنوان الشبكة ووكيل المستخدم. RPC يتحقق مرة أخرى من المفاتيح والقيم، ويدون التغيير والـaudit في transaction واحدة.

## المفاتيح المدعومة

| المفتاح | الافتراضي | الأثر |
|---|---:|---|
| `ui.default_theme` | `light` | الافتراضي للمستخدمين الذين لم يختاروا ثيمًا |
| `ui.default_language` | `ar` | الافتراضي للمستخدمين الذين لم يختاروا لغة |
| `ui.allow_theme_override` | `true` | يمنع تغيير الثيم من جميع عناصر الواجهة عند إيقافه |
| `ui.allow_language_override` | `true` | يمنع تغيير اللغة من جميع عناصر الواجهة عند إيقافه |
| `system.maintenance_mode` | `false` | يعرض صفحة صيانة ويحجب الاستخدام العادي من API، مع إبقاء Admin وruntime-config والصحة متاحة |
| `features.registration_enabled` | `true` | يوقف إنشاء تسجيلات جديدة بخطأ مفهوم، دون تغيير تسجيل الدخول أو JWT |
| `features.guest_scans_enabled` | `true` | يمنع endpoint فحص الضيف؛ تبقى فحوصات الحسابات المسجلة متاحة |
| `features.public_metrics_enabled` | `true` | يخفي الإحصاءات العامة ويوقف جمع زيارات صفحة الترحيب |
| `features.ai_explanations_enabled` | `true` | يوقف استدعاءات Gemini للتفسير؛ يبقى التحليل المحلي/المحركات الأخرى متاحًا |
| `legal.require_latest_terms` | `false` | يطلب موافقة صريحة على أحدث نسخة شروط قبل استخدام مساحة الحساب |

الإعدادات الافتراضية لا تستبدل تفضيل مستخدم محفوظ طالما التغيير مسموح. عند حجب تعديل اللغة أو الثيم، تطبق قيمة Admin افتراضيًا وتُهمل القيمة المحلية القديمة.

## حدود التشغيل

تُخزّن الإعدادات في `public.system_settings`، ويُفعّل لها RLS مع منع `anon` و`authenticated` من أي صلاحية مباشرة. يملكها Backend عبر `service_role`. يحتفظ كل مثيل Backend بنسخة مؤقتة لمدة لا تتجاوز خمس ثوانٍ؛ بعد تحديث Admin تُمسح ذاكرة النسخة الحالية، بينما تنتهي ذاكرات بقية النسخ خلال مدة الـTTL. عند تعذر قراءة الإعدادات، تُمنع عمليات الاستخدام المعتادة أو تُعطّل الخصائص الاختيارية بدل كشفها أو تشغيلها دون تحقق.
